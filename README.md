## 📌 About the Project

Customer Churn Analysis and Prediction Using AI is a Machine Learning and Data Analytics project that analyzes customer data and predicts whether a customer is likely to leave a company.

The project uses data analysis, visualization, and machine learning to understand customer behavior and identify customers who are at risk of churn.

---

## 🎯 Objectives

- Analyze customer churn data
- Clean and preprocess the data
- Understand customer behavior
- Visualize important churn patterns
- Build Machine Learning models
- Predict customer churn
- Generate useful business insights

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly
- Streamlit

---

## 🤖 Machine Learning Models

The project uses:

- Logistic Regression
- Decision Tree
- Random Forest

---

## 📊 Dataset

The project uses the **Telco Customer Churn Dataset**.

The dataset contains information about customers such as:

- Customer details
- Tenure
- Contract type
- Internet service
- Payment method
- Monthly charges
- Total charges
- Churn status
